# Naqsh user guide (beta)

Naqsh is free, open-source relief-carving CAD/CAM that runs in your browser: draw vectors, build 3D
reliefs, make toolpaths, simulate them and export G-code for your CNC router.

**Open the beta:** <https://hariskhan2010.github.io/ARTSCAM/>. It works offline after the first visit
and can be installed from the browser menu ("Install app").

> **Read [Before the first cut](02-before-the-first-cut.md) before you run any file on a machine.**
> This is beta software. Air-cut first, every time.

## Getting help

- **Report a problem:** Help › Report a problem opens a pre-filled issue on GitHub. Attach your
  project file (File › Save) and, for machining problems, the exported `.nc` file.
- Ideas and questions are welcome as GitHub issues too.
