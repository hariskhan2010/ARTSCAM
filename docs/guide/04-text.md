# Text

1. Pick **Text (T)** and click where the text should go.
2. Type in Urdu, Arabic or English (or a mix). Letters join and stack as they should; the
   preview updates as you type.
3. Choose a **font**: Naskh and Nastaliq are built in (with Latin letters), or **Load a font
   file…** (TTF, OTF or WOFF).
4. Set the **size** (the em height; capitals are about 70–75 % of it) and the **alignment** to the
   click point.
5. **Add text** (Ctrl+Enter). Escape cancels.

The text becomes one closed shape, ready for V-carving or a relief.

## Changing text later

Select the text and press **Edit text** in the Selected shape panel. Change the wording, font,
size or alignment, then **Update text**. It stays where you put it, even after moving, rotating
or resizing it. Ctrl+Z undoes the edit in one step.

Editing the points, offsetting or combining the text with other shapes turns it into a plain
shape: after that it can no longer be edited as text.

If a font has no glyph for a character, the card says which characters are missing.
